What do P, I and D do?
  • P (proportional) pushes in proportion to the error. Higher is faster, but too high overshoots or oscillates, and P alone usually leaves a steady error.
  • I (integral) adds up past error, so it removes that leftover error and recovers from disturbances. Too much makes it overshoot and swing.
  • D (derivative) reacts to how fast the output is changing, so it damps overshoot. It also amplifies sensor noise, so turn on noise and raise Kd to see it.
  • Anti-windup stops the integral from piling up while the controller is maxed out. Turn it off and ask for a big jump to see the extra overshoot.

Error is measured as a fraction of each system's range, so the same gains behave similarly across the three systems. Derivative uses the measurement, not the error, to avoid a spike when the target jumps.
