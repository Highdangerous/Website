# Tidy (web)

A browser version of the `tidy` CLI. Nothing is uploaded; files are read locally in your browser.

- **Organize**: drop files and see them grouped into Images, Documents, and so on. Download a `.zip` with the sorted folders.
- **Rename**: pick a prefix and start number, preview the new names, download a `.zip` of the renamed files.
- **CSV summary**: drop a CSV to see each column's type, missing values, unique count, and stats.

## Run it

Open `index.html` in your browser, or run `python3 -m http.server 8000` from the repo root and visit http://localhost:8000/tidy-web/.
